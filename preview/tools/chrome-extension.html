Chrome Extension — Mirsad Analytics
Tools · Chrome extension Live

How the Chrome extension works.

The core Mirsad product: it reads a live Amazon listing in your own browser and shows you the real numbers behind it, price, fees, net revenue, and a listing quality read, without leaving the page you're already on.

Now live: Mirsad Analytics is on the Chrome Web Store and works on amazon.ae, amazon.sa and amazon.eg. Install it free.
How to use it

Install the extension

Chrome, Manifest V3. No account, no setup screen, nothing else to configure first.

Search or browse Amazon as normal

Amazon.ae, Amazon.sa, or Amazon.eg. The panel works on search results pages, exactly the way you already research. Support for individual product pages is coming soon.

Open the panel

A results table appears over the page, draggable and resizable, enriching every visible product with the fields below.

Pick your columns and export

Use the column picker to show only what a given research pass needs. Select specific rows or leave nothing selected to export everything visible as a CSV file.

What appears in the panel
PRICE / RATING / REVIEWS
Read live from the rendered page.
BSR / CATEGORY / BRAND
Pulled from each listing's own product data.
FULFILLMENT / SELLERS
Who's fulfilling it, how many sellers are competing.
DIMENSIONS / WEIGHT
Feeds the FBA size-tier fee directly.
REFERRAL + FBA FEE
From that marketplace's own published fee schedule.
NET REVENUE / TIER
Price minus real fees.
LISTING QUALITY SCORE
Built from what's actually on the page.
CSV EXPORT
Selected rows, or everything visible.
